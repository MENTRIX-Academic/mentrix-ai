# TAFlow — تجربة Stress Testing ومقارنة الموديلز

**تاريخ النسخة:** 28 أكتوبر 2026

## اتعمل إيه؟
- أبقينا الأسئلة الخمسة القديمة في مسار **Essay / Descriptive** (وآخر سؤال محتاج فصل الجزء الحسابي مستقبلًا).
- حافظنا على `grader.py` (النسخة القديمة) للتوثيق والمقارنة.
- أضفنا `grader_v2.py` لتصحيح **MCQ / Short Answer من 1–3 كلمات / Math** بصورة أكثر تحفظًا.
- أضفنا **123 حالة ضغط Synthetic** و20 Unit Test جديدة (إجمالي الاختبارات 24/24 PASS)، واختبار 500 مدخل عشوائي مشوه بدون Exceptions غير معالجة.
- جربنا **Strict vs Type-Aware V1 vs Type-Aware V2** وراجعنا 127 حالة الاختبار القديمة.
- كتبنا تقريرًا كاملًا للمقارنة مع الموديلات السابقة **TF-IDF / SBERT / NLI / Rubric+SBERT / Rubric+NLI**.
- **ما جربناش OCR ولا خط يد ولا درّبنا موديل**.

## النتائج المختصرة
| النوع | عدد حالات Stress | V1 Agreement | V2 Agreement | V2 Review |
|---|---:|---:|---:|---:|
| MCQ | 27 | 85.2% | 100% | 12 |
| Short | 47 | 72.3% | 100% | 20 |
| Math | 49 | 87.8% | 100% | 19 |

**مهم:** دي مطابقة لقرارات مكتوبة مسبقًا داخل اختبارات مصطنعة **مش Accuracy حقيقية**. عدّلنا V2 بناءً على نفس الحالات؛ نتيجة 100% مش اختبار مستقل.

الـV2 أحال 51 من أصل 123 حالة للمراجعة (41.5%)؛ المراجعة **مش خطأ تصحيح** لكنها عبء إضافي على الـTA. مقارنة الموديلز القديمة غير قابلة للمقارنة رقميًا مباشرة مع النتائج دي لأن نوع الداتا والمقاييس مختلفين.

## افتحي إيه؟
- **TAFlow_Research_Report.docx:** التقرير الرسمي بالإنجليزي والمقارنة مع الموديلز القديمة.
- **REPORT_EN.md:** نفس التقرير النصي.
- **stress_summary.csv:** أرقام المقارنة الجديدة.
- **stress_predictions.csv:** قرار كل Method لكل حالة وسبب القرار.
- **stress_cases.csv:** أسئلة الاختبار المصطنعة.
- **grader.py:** النسخة القديمة بدون تعديل.
- **grader_v2.py:** النسخة المُحسّنة (مش Production).
- **test_grader.py + test_v2.py:** الاختبارات.
- **run_stress.py:** تشغيل المقارنة الجديدة.
- **run_regression.py:** تجربة V2 على الـ127 حالة القديمة.
- **run_fuzz_smoke.py:** فحص 500 إدخال عشوائي للكشف عن انهيار البرنامج؛ مش دليل أمان أو دقة.
- **questions.json:** نوع كل سؤال وAnswer Keys.
- **HANDWRITING_QUIZ_READY_TO_PRINT.html:** الورقة اللي هنجمع عليها الإجابات في المرحلة القادمة؛ **لم نبدأ اختبار OCR**.

## تشغيليها إزاي؟
فكي الضغط، وافتحي الفولدر، ودوسي مرتين على `START_HERE.bat`.
لو البرنامج طلب تثبيت SymPy: افتحي PowerShell داخل نفس الفولدر واكتبي `py -m pip install sympy` ثم افتحي الملف تاني.

## الاعتماد والتقييم
بناءً على طلبك، هنعتبر سؤال الكويز ومفتاح الإجابة والـRubric **معتمدين كافتراض عمل**؛ ده غير تقييم بشري مستقل. قبل إعلان دقة حقيقة، مطلوب إجابات بشرية مجهّلة ودرجات بشرية مستقلة وحجز Test Set منفصل.

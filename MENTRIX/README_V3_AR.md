# MENTRIX V3 — تحسين OCR + إضافة Chatbot (تشغيل محلي)

## ابدئي من هنا

1. فكي ضغط `MENTRIX_OCR_CHATBOT_V3.zip` بالكامل في فولدر جديد، **من غير دمج** مع النسخة القديمة. هذا يحفظ ملفات `grader.py`, `grader_v2.py`, `adapter.py`, `questions.json` الأصلية.
2. شغّلي `START_MENTRIX_V3.bat` من داخل الفولدر. الملف بيستخدم اكتشاف Python 3.12 المحلي (`DETECT_PYTHON.bat`) زي النسخة السابقة. **اتركي نافذة CMD مفتوحة**.
3. في Chrome افتحي: `http://127.0.0.1:8010/` لتصحيح الإجابات المكتوبة، أو `http://127.0.0.1:8010/ocr` لقراءة الخط، أو `http://127.0.0.1:8010/chatbot` للمساعد.
4. لو أول تشغيل TrOCR ظهر خطأ `transformers` أو `torch`، شغّلي `INSTALL_OCR_ONCE.bat` (مكتبات وأوزان الموديل حجمها كبير وقد تحتاج إنترنت). لو سبق اشتغل TrOCR على جهازك بنفس Python، **ما تعيديش التثبيت من غير سبب**.
5. لو البورت 8010 مستخدم عندك، اقفلي السيرفر القديم بـ`Ctrl+C` قبل ما تشغّلي الجديد.

## تحسينات الـOCR الفعلية

- `Suggest line cuts` بيحاول يقترح فواصل بين سطور الكتابة بخوارزمية تحليل صفوف الحبر (Projection). **الاقتراح مش مضمون ومش معتمد تلقائيًا؛** لازم تعدلي الخطوط الحمراء بحيث ما تقطعش أي حرف أو علامة.
- اختيار **E01 Original RGB** يحافظ على نفس مسار الـBaseline السابق. اختيار **Original RGB + Autocontrast** يشغّل TrOCR مرتين على نفس السطور. ده ممكن يساعد في بعض السطور ويضر سطورًا أخرى؛ **مفيش اختيار آلي للأفضل ولا Accuracy محسوبة من غير Ground Truth**.
- في STEP 03 هتلاقي مرشّح Original وAutocontrast لكل سطر، واختاري الأنسب كبداية للنقل، ثم راجعي النص كلّه مقابل الصورة. الصندوق `OCR QA flags` يلفت النظر للسطور الفارغة/الباهتة أو المخرجات المريبة، **مش Confidence score**.
- الفرق بعد أي تعديل يُقاس فقط بعد وجود Ground Truth بشرية مستقلة، وبـCER/WER حسب نفس منهج التقييم، وبدون إعادة استخدام عينات التطوير كاختبار مستقل.

### تجربة بسيطة

1. اختاري E01 (السؤال المقالي عن Continuous/Discrete) وارْفعي صورة إجابة **سؤال واحد** مع إزالة أي اسم أو رقم طالب.
2. اضغطي `Suggest line cuts` ثم حرّكي/زودي الفواصل يدويًا؛ أكّدي سلامة القص.
3. من `OCR comparison mode` اختاري `Original RGB + Autocontrast`. بعد التشغيل، قارني النصين لكل سطر وجرّبي `Use selected lines as editable draft`، وبعدها صحّحي الـGround Truth يدويًا.
4. اضغطي Verify text، وهتلاقي Essay بيروح لـTA Review بدون Auto-score. اعتمدي الدرجة يدويًا حسب الـRubric، وهتتحفظ في SQLite المحلي التجريبي.

## الـChatbot نوعه إيه؟

- صفحة `/chatbot` بتشتغل فورًا **من غير إنترنت أو API key** في وضع `Offline Knowledge`. بتبحث في قاعدة معلومات محلية محدودة: خطوات OCR، مرحل المشروع، مفاهيم Continuous/Discrete، Sine/Square، Parameters، WER/CER. بتعرض عنوان/مصدر المعلومة. ده **Retrieval chatbot** حقيقي لكنه **ليس LLM توليديًا أو مدرّبًا على ملفات الطلاب**.
- `Local Ollama` اختياري عشان إجابات أكثر حوارية: لازم Ollama نفسه يكون متثبت وشغّال محليًا ومعاه موديل مناسب. لا نُثبّته أو ننزّل أوزانه ضمن ZIP. حددي اسم الموديل في متغير بيئة `MENTRIX_OLLAMA_MODEL` (الافتراضي `llama3.2:3b`). تقدرِي تستخدمي `Ollama` فقط لو شغال على `127.0.0.1:11434`؛ ولو غير موجود بيظهر خطأ واضح **مش رد مزيف**.
- Chatbot لا يصل لسجلات الطلاب أو الصور أو مفاتيح الإجابات أو قاعدة درجات SQLite. مش Agent مستقل وما بيعدّلش درجات، ولا فيه تسجيل دخول أو صلاحيات حقيقية للمعيد والطالب حتى الآن.

## هيكل الكود الجديد

- `ocr_quality.py` = اقتراح تقسيم السطور + Autocontrast + تحذيرات جودة، كلها Heuristics قابلة للمراجعة.
- `ocr_integration.py` = `/api/v1/ocr/suggest-lines` + `/transcribe` + SQLite + `verify/approve`؛ تم إضافة `candidates_json` و`quality_json` مع **migration** لقواعد البيانات القديمة.
- `chatbot_integration.py` = قاعدة المعرفة و`/api/v1/chatbot/ask` وOptional local Ollama.
- `static/chatbot.html/css/js` = صفحة chatbot، و`static/ocr.html/js/css` = تحسينات واجهة OCR.
- `ocr_tests/test_v3_ocr_chatbot.py` = اختبارات features الجديدة، مع Mock لتوقعات TrOCR (لا تثبت جودة قراءة فعلية).

## نتائج المشروع السابقة التي لا تتغير بهذا التحديث

- Old E01 على 7 إجابات: CER **25.60%** / WER **57.69%**.
- Segmentation V2 اليدوية على **نفس** العينات السبع: CER **15.58%** / WER **50.09%**.
- لم يجر اختبار دقة جديد لواجهة V3؛ لا تدّعي تحسّن CER/WER من مجرد تغيير الكود. ما زال المطلوب مجموعة اختبار مستقلة ومسار مراجعة بشرية.

## القيود والخصوصية

**LOCAL RESEARCH PILOT ONLY.** افتحي السيرفر على `127.0.0.1` فقط. لا توجد حسابات طلاب، Authentication/RBAC، أو تخزين مشفّر. صور الإجابات وقاعدة SQLite تُحفَظ في `local_private_data/` على جهازك، ولا ترفعي بيانات شخصية حساسة. لا يوجد Essay AI grading model تم التحقق منه، ولا نظام Quiz Generation/QR Attendance ضمن هذه النسخة. إجابات Chatbot المحلي ليست معتمدة أكاديميًا ويجب التحقق منها.

## فحص سريع

شغّلي `RUN_TESTS_V3.bat`. اختبارات الـOCR بتستخدم Mock لأنها لا تنزّل موديل TrOCR في الفحص. تشغيل TrOCR الفعلي لازم يتجرّب على كمبيوترك قبل الاعتماد. تفاصيل الـAPI متاحة عند `http://127.0.0.1:8010/docs`.
